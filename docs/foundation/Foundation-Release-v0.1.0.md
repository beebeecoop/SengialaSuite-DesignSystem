# Foundation Release v0.1.0

**Codename:** Foundation Stone  
**Status:** Approved Foundation Architecture

## Purpose

This release establishes the first formal baseline for the Sengiala Design Platform and defines the relationship between SDP, SDS, SDT and SDC.

## Included artefacts

- SDP-001 through SDP-005
- SDS-001 through SDS-003
- SDT-001
- SDC-001
- Foundation Stone, roadmap, changelog and lessons learned

## Release outcome

The repository becomes the single source of truth for design standards, token architecture and reusable component architecture across the M5 SengialaSuite ecosystem.

## Non-goals

This release does not provide production Flutter or Web packages, final brand assets or a complete component catalogue.
