# Foundation Stone

## Declaration

SengialaSuite-DesignSystem is the official design platform for the M5 SengialaSuite ecosystem.

The platform unifies four artefact families:

1. SDP — Sengiala Design Platform
2. SDS — Sengiala Design System
3. SDT — Sengiala Design Tokens
4. SDC — Sengiala Design Components

## Foundational principle

One design language shall serve multiple Sengiala products while preserving accessibility, trust, consistency and maintainability.

## Scope

This Foundation Stone governs the design foundations for web, mobile, dashboard, Mission Control and future platform surfaces.

## Decision

Foundation Release v0.1.0 establishes architecture and governance before implementation packages are created.
