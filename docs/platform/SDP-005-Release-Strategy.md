# SDP-005 — Release Strategy

## Versioning

The platform follows semantic versioning.

- Patch releases provide compatible corrections.
- Minor releases add compatible standards, tokens or components.
- Major releases may introduce breaking contracts.

## Release gates

A release must include reviewed documentation, compatibility assessment, accessibility consideration, changelog entries and migration guidance where required.

Foundation v0.1.0 establishes documentation contracts only. Package publication begins in a later release.
