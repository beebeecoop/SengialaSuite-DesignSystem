# SDC-001 — Component Architecture

## Purpose

Sengiala Design Components turn SDS standards and SDT values into reusable, accessible interface building blocks.

## Component layers

1. Foundations — text, icon, surface and layout primitives.
2. Controls — buttons, inputs, selection and feedback.
3. Navigation — app bars, drawers, tabs and bottom navigation.
4. Data display — cards, tables, KPI views and charts.
5. Patterns — forms, empty states, error states, offline states and workflows.

## Contract

Every component shall define anatomy, states, behaviour, token dependencies, accessibility requirements, responsive behaviour and platform adaptations.

## Initial catalogue direction

Button, Text, TextField, Card, Dialog, Snackbar, Navigation, AppBar, Bottom Navigation, Drawer, KPI Card, Dashboard Widget, Data Table, Chart, Form, Loading, Empty, Error and Offline states.
