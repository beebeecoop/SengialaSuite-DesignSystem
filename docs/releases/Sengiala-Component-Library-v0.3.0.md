# Sengiala Component Library v0.3.0

## Release title

Core Component Foundation

## Engineering sprint

DS-002 — Sengiala Design Components

## Scope

This release establishes the first executable Flutter package for Sengiala Design Components. It converts the approved SDS and SDT foundations into reusable interface building blocks.

## Delivered

- Package and public API baseline
- Light, dark and high-contrast theme entry points
- Spacing, radius, duration and icon-size contracts
- Button and icon button
- Text field
- Surface and card
- Avatar, badge and chip
- Progress indicator
- Widget test baseline
- Package usage documentation

## Component maturity

All components enter at **L2 — Prototype**. Promotion to **L3 — Verified** requires successful analysis, widget tests, accessibility review, golden tests and responsive/theme validation in a Flutter-enabled CI environment.

## Release constraints

This is a foundation release. API changes remain possible until the component contracts are verified in at least one SengialaSuite application.

## Next release direction

- Complete divider and selection controls
- Add form, navigation, feedback and data-display families
- Replace interim constants with generated SDT assets
- Add golden and accessibility test suites
